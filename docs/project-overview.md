# Project Overview: JeepTours2

## Проблема
Туристи та любителі активного відпочинку часто стикаються з складністю вибору та планування оффроуд-маршрутів (джип-турів) у гірській місцевості. Важко самостійно підібрати підходяще авто, оцінити складність, розрахувати таймінг та врахувати вимоги до безпеки.

## Цільова аудиторія
Туристи, екстремали та сімейні мандрівники, які шукають індивідуальні або групові джип-тури з різним рівнем складності та специфічними вподобаннями (наприклад, водоспади, оглядові майданчики, Говерла).

## Основний сценарій (MVP)
Користувач відкриває Android-додаток, вказує тривалість поїздки в годинах, обирає рівень складності (EASY, MEDIUM, HARD) та вводить текстові вподобання. Після натискання кнопки «Згенерувати маршрут» додаток надсилає запит на FastAPI backend, який аналізує параметри та повертає згенеровану картку туру з рекомендованим авто, альтернативними варіантами, погодинним графіком та порадами з безпеки.

## Межі MVP (Scope)
- **Включено:** Введення параметрів, виклик HTTP API backend, динамічне формування туру, перемикання варіантів (Варіант 1 / Варіант 2), обробка станів завантаження та мережевих помилок (Retry).
- **Виключено (на поточний момент):** База даних, авторизація користувачів, онлайн-оплата, інтерактивна GPS-карта, збереження історії турів.

# AI Coding Agent Instructions (Behavioral Rules)

Даний файл є системним контрактом для будь-якого AI / Coding-агента, який працює з даним репозиторієм.

## Обов'язкові правила:
1. **Читання контексту:** Перед внесенням будь-яких змін обов'язково прочитай документацію у папці `docs/` та перевір структуру файлів проєкту.
2. **План дій:** Спочатку поясни поточну реалізацію, сформуй план і перелічи точні файли, які потрібно змінити.
3. **Локальні зміни:** Не переписуй весь проєкт чи незв'язані модулі для виконання однієї локальної задачі.
4. **Збереження контракту:** Не змінюй `docs/api-contract.md` або DTO-моделі без попереднього узгодження та обґрунтування.
5. **Залежності:** Не додавай нові зовнішні бібліотеки чи Gradle-залежності без чіткого пояснення.
6. **Безпека:** Ніколи не хардкодь API-ключі, секрети або персональні дані у коді чи комітах.
7. **Збереження сумісності:** Будь-які зміни не повинні ламати існуючий основний сценарій Лаб.2 (генерація джип-турів).
8. **Тестування:** Завжди пропонуй або оновлюй перевірочні сценарії/тести для нової поведінки.
9. **Підсумок:** Після реалізації надай короткий підсумок змін, команди для перевірки та зміни, які слід внести в Knowledge Base.

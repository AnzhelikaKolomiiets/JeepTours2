# Known Limitations: JeepTours2

## Відомі обмеження та технічний борг
1. **In-Memory State:** Згенеровані тури не зберігаються локально в DB (Room). При перезапуску застосунку дані скидаються.
2. **Мережева залежність:** Застосунок не має повноцінного offline-режиму (якщо немає зв'язку з бекендом, згенерувати новий тур неможливо).
3. **Обмежена валідація:** На клієнті відсутня жорстка валідація від'ємної тривалості або занадто довгих текстів до відправки на сервер.
4. **Статичні варіанти:** Кількість варіантів маршруту обмежена двома на кожен запит.

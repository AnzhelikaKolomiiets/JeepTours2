# Requirements: JeepTours2

## Функціональні вимоги
1. **Введення даних:**
    - Поле `duration_hours` (числове, тривалість у годинах).
    - Вибір `difficulty` (enum: `EASY`, `MEDIUM`, `HARD`).
    - Поле `preferences` (текстове, опис бажаних локацій/цілей).
2. **Генерація туру:**
    - Надсилання POST-запиту на backend за адресою `/generate_route`.
    - Повернення назви туру, рекомендованого авто та списку варіантів маршруту.
3. **Відображення результату:**
    - Відображення картки з деталями туру.
    - Підтримка кнопками перемикання між «Варіант 1» та «Варіант 2».
4. **Обробка станів UI:**
    - Відображення стану завантаження під час запиту.
    - Обробка помилок мережі (таймаут/недоступність бекенду) з відображенням повідомлення та кнопки «Повторити спробу».

## Нефункціональні вимоги
- **Сумісність:** Android 10+ (minSdk 29).
- **Час відповіді:** Отримання результату від бекенду за < 2 секунд за нормальних умов мережі.
- **Стійкість:** Застосунок не повинен аварійно завершуватися (CRASH) при відсутності мережі або некоректних даних.

## Критерії готовності (Acceptance Criteria)
- [x] Форма введення приймає тривалість, складність та текстовий описовий запит.
- [x] При доступному бекенді відображаються коректні варіанти турів з деталізованим розкладом.
- [x] При вимкненому бекенді показується помилка та кнопка «Повторити спробу».

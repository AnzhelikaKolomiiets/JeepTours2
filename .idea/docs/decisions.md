# Architectural Decisions (ADR): JeepTours2

## ADR-001: Використання FastAPI для бекенду
- **Контекст:** Необхідно швидко розгорнути REST API з автодокументацією та валідацією.
- **Рішення:** Обрано Python + FastAPI + Pydantic.
- **Причина:** Простота створення POST-ендпоінтів, вбудована JSON-валідація та висока швидкість розробки для MVP.

## ADR-002: Jetpack Compose для мобільного UI
- **Контекст:** Потрібно реалізувати гнучкий інтерактивний інтерфейс з обробкою станів.
- **Рішення:** Використання Jetpack Compose (Declarative UI).
- **Причина:** Зручне перемикання станів `Idle`, `Loading`, `Success`, `Error` та кнопкова багатоваріантність.

## ADR-003: Адресація 10.0.2.2 для Android-емулятора
- **Контекст:** Емулятор Android працює у віртуальній мережі та не бачить `localhost` хоста безпосередньо.
- **Рішення:** Базовий URL у Retrofit налаштовано на `http://10.0.2.2:8000/`.
